# 獬豸安码品牌字体

本目录集中保存系统总览品牌标题实际使用的字体，项目复制到其他电脑后可直接由浏览器加载，不依赖操作系统是否安装这些字体。

- `huangling.ttf`：用户提供的原始 QIJIFALLBACK 字体，已确认 `獬`、`豸` 都有非空字形轮廓。
- `HuangLing-XieZhi.woff2`：仅包含 `獬豸` 的网页子集。
- `HanWangInJang.ttf`：用户提供的王汉宗印篆体原始字体。
- `HanWangInJang-AnMa.woff2`：仅包含 `安码` 的网页子集；原字体没有简体 `码`，因此将繁体 `碼` 的字形映射到简体字符 U+7801。

页面只加载两个很小的 WOFF2 子集，原始 TTF 留在这里用于后续重新生成或更换子集。
