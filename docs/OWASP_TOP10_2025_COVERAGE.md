# OWASP Top 10:2025 检测覆盖说明

## “覆盖”的工程定义

本项目对 OWASP Top 10:2025 十个大类提供基础静态检测入口、证据行、CWE、修复建议和官方参考链接。

这里的“基础覆盖”不等于以下承诺：

- 覆盖十个大类下的每一个 CWE；
- 覆盖所有语言、框架和跨文件数据流；
- 能仅凭静态源码判断全部业务逻辑、部署配置和运行时问题；
- 零误报、零漏报。

检测 API 使用 `coverage_level: baseline`，并明确返回
`absolute_coverage_claimed: false`，防止把基础覆盖误写成绝对全覆盖。

## 十类基础检测

| 类别 | 当前基础信号 | 主要局限 |
|---|---|---|
| A01 访问控制失效 | 对象标识直查、路径穿越、SSRF | 完整授权需跨路由、身份和数据所有权分析 |
| A02 安全配置错误 | 调试模式、关闭 TLS 校验、危险 CORS | 最终网关和云配置可能不在源码中 |
| A03 软件供应链失效 | 安装钩子、远程下载、下载后执行 | 仍需 SBOM、制品签名和联网漏洞情报 |
| A04 密码学失效 | 弱哈希、ECB、弱随机、硬编码密钥 | 密钥生命周期和实际 TLS 参数需环境证据 |
| A05 注入 | SQL 注入、XSS、命令注入及部分数据流 | 尚未覆盖所有框架的完整污点传播 |
| A06 不安全设计 | 前端单独授权、无边界操作、异常放行 | 业务逻辑仍需威胁建模和人工评审 |
| A07 身份认证失效 | JWT 关闭验签、明文口令比较、凭据暴露 | MFA、恢复和会话撤销需跨服务验证 |
| A08 软件或数据完整性失效 | 不安全反序列化、未验证远程载荷、安装钩子 | 发布链和签名需制品与流水线证据 |
| A09 安全日志与告警失效 | 敏感数据日志、日志注入 | “缺少日志”通常不能由单文件直接证明 |
| A10 异常条件处理不当 | 空异常处理、堆栈外泄、异常放行、无边界资源 | 真实恢复能力还需故障注入和压力测试 |

可执行注册表位于 `backend/attack_detection/owasp_coverage.py`。

## 修复建议知识库

修复建议由以下两个本地文件合并并按文本去重：

- `backend/attack_detection/remediation_catalog.json`
- `backend/attack_detection/remediation_catalog_owasp2025.json`

当前统计为 43 个风险类别、328 条唯一修复建议，其中包含 31 条语言专项建议。
新增内容按 OWASP Top 10:2025 与 OWASP Cheat Sheet Series 归纳为中文，
每个类别保留来源链接；它们不是模型临时生成的未审核文本。
