# 开源与数据说明

## 开源组件

系统主要使用 Flask、Flask-Login、scikit-learn、matplotlib、joblib、Bootstrap、Bootstrap Icons 和 Chart.js。上述组件均为通用开源组件，仅用于 Web 服务、模型训练、页面展示和统计图表渲染。

## 数据说明

样例训练数据位于 `backend/data/sample_dataset/code_samples.csv`，字段为 `code`、`label`、`category`、`language`。数据集包含 75 条人工构造的教学与演示样本，不包含真实用户隐私数据、真实密钥或未授权代码。

数据覆盖以下类别：
- SQL 注入
- XSS
- WebShell
- 命令执行
- SSRF
- 路径穿越
- 反序列化风险
- 敏感信息泄露
- 恶意下载/远程加载
- 混淆逃逸/编码隐藏
- 安全代码样例

## 模型说明

默认推荐训练方式为 TF-IDF + RandomForest。训练器同时保留 Logistic Regression、Linear SVM 和 RandomForest 选项。模型文件保存到 `backend/models/`，应用启动时优先加载磁盘模型；缺少模型时会自动使用启发式检测兜底，保证演示稳定。

## 原创性说明

规则库、风险评分、项目扫描、可解释报告和演示数据均围绕本作品主题自行设计。第三方开源库只作为基础框架和机器学习工具使用，不包含外部商业产品或已发表作品的核心实现。
