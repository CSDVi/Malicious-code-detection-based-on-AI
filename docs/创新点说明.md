# 创新点说明

1. 从单点漏洞检测升级为软件供应链攻击代码检测，覆盖源代码、脚本和项目包。
2. 规则、机器学习、语义启发式三引擎融合，兼顾已知攻击特征和未知可疑模式。
3. 每条规则内置修复建议，使告警从“发现问题”延伸到“指导整改”。
4. 支持 zip 项目批量扫描，输出项目风险总览、攻击类型分布和高危文件 Top 10。
5. 提供模型评测页面，用准确率、召回率、F1、误报率和混淆矩阵增强作品可验证性。
6. 检测结果保留证据行、风险原因、修复建议、引擎投票和置信度，提升 AI 安全系统的可解释性。

## 应用价值

獬豸安码可用于课程实训、开源项目自查、企业代码上线前安全门禁和软件供应链风险排查。系统强调批量扫描、可解释告警和可复现实验指标，更贴近真实安全工程流程。
