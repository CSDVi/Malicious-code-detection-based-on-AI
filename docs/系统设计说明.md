# 系统设计说明

## 背景

软件供应链攻击常通过源代码后门、构建脚本、依赖配置、远程下载链路和混淆载荷进入项目。传统人工审计成本高、覆盖面有限，獬豸安码将 AI 模型与规则知识库结合，用于快速发现代码级攻击特征并给出可解释修复建议。

## 总体架构

系统由 Web 展示层、检测服务层、模型评测层和数据持久层组成。

1. Web 展示层：Flask 蓝图提供单文件扫描、项目扫描、历史记录、统计图表和模型评测页面。
2. 检测服务层：`attack_detection.scanner` 汇总规则引擎、机器学习引擎和语义启发式引擎。
3. 规则知识库：`attack_detection.rules` 覆盖 10 类攻击风险，每条规则包含编号、类型、严重度、描述和修复建议。
4. 机器学习层：`attack_detection.trainer` 使用 TF-IDF 特征训练 Logistic Regression、Linear SVM 或 RandomForest。
5. 项目扫描层：`attack_detection.project_scanner` 安全解压 zip，批量扫描多语言源码文件并生成项目级风险总览。
6. 数据持久层：SQLite 保存检测历史和统计信息。

## 多引擎融合

规则引擎负责高精度命中已知攻击模式；机器学习模型对代码文本进行恶意/正常二分类；语义启发式引擎判断危险函数、外部输入和混淆特征是否同时出现。系统依据规则严重度、攻击类型数量、模型投票和关键高危类型生成综合分数。

## 可解释输出

每次扫描输出证据行、风险原因、修复建议、三引擎投票、最终结论和综合置信度。
