# 多语言深度模型下载与接入

## 先说明边界

预训练代码模型不等于恶意代码或漏洞检测器。下载基础权重后，必须使用本项目的
`malicious_intent` 和 `vulnerability_risk` 标签训练分类头，并在每种语言的独立
train/validation/test 分区上通过门禁，才能进入运行时。第三方成品分类器也必须先
作为 candidate 复测，不能仅凭其模型卡指标直接发布。

当前机器的深度环境是 CPU 版 PyTorch，未检测到 NVIDIA CUDA。默认不下载 3B 以上
生成模型；模型越大不等于本地检测越准。

## 推荐路由

| 模式 | 下载权重 | 目标语言 | 接入定位 |
|---|---|---|---|
| quick | `huggingface/CodeBERTa-small-v1` | Python、Java、JS、PHP、Go、Ruby | 84M 轻量编码器；训练恶意意图/漏洞双任务头后做快速深度筛查 |
| quick 候选 | `ayshajavd/graphcodebert-vuln-classifier` | Python、JS、Java、C/C++、PHP、Go | 下载即有 31 类输出，但只能作 bootstrap；稀有 CWE precision 很低，PHP/Go 偏弱 |
| standard | `microsoft/graphcodebert-base` | Python、Java、JS、PHP、Go、Ruby | 引入 data-flow 表征；需要对应语言 parser 和双任务 fine-tuning |
| deep | `Salesforce/codet5p-220m` | C/C++/C#、Go、Java、JS、PHP、Python、Ruby | 深层语义候选，与现有 ByteCNN-TCN、项目 GATv2 组成互补验证 |
| deep-wide（可选） | `Qwen/Qwen2.5-Coder-0.5B` | 官方称覆盖 92 种编程语言 | 用于 Shell、TypeScript 和冷门语言候选；CPU 较慢，必须做分类 fine-tuning 与 INT8/ONNX 基准 |

## 下载

在项目根目录执行：

```powershell
D:\software\anaconda\envs\drone\python.exe -m pip install -r backend\requirements-transformer.txt

# 先看将下载什么
D:\software\anaconda\envs\drone\python.exe scripts\download_deep_models.py --profile all --list

# 分批下载，便于确认磁盘与网络
D:\software\anaconda\envs\drone\python.exe scripts\download_deep_models.py --profile quick
D:\software\anaconda\envs\drone\python.exe scripts\download_deep_models.py --profile standard
D:\software\anaconda\envs\drone\python.exe scripts\download_deep_models.py --profile deep

# 只有确实需要 Shell/冷门语言深度候选时再下载
D:\software\anaconda\envs\drone\python.exe scripts\download_deep_models.py --profile deep-wide
```

下载位置：`backend/models/pretrained/`。下载器只取 PyTorch/Safetensors 和 tokenizer，
不拉取重复的 TensorFlow、Flax、Rust 权重。

## 下载后的必做步骤

1. 为 PHP、JavaScript/TypeScript、Go 分别准备 benign/malicious/vulnerable 样本；每种任务、每种语言在 train/validation/test 都必须有正负两类。
2. 基础权重分别训练 `malicious_intent` 与 `vulnerability_risk` 分类头；不要拿语言识别或代码补全 logits 直接当风险概率。
3. 固定独立 external holdout，至少报告样本数、precision、recall、F1、FPR、FNR，并按语言展示。
4. 通过门禁后导出 ONNX/INT8，记录 tokenizer、max length、阈值、模型哈希和数据集哈希。
5. quick、standard、deep 只启用已经通过语言门禁的 head；不支持的语言必须返回 `Unavailable`，不能伪造概率。

建议最终运行结构：

```text
quick    = 规则/静态证据 + 多语言 CodeBERTa-small 双任务头
standard = quick + GraphCodeBERT 数据流双任务头 + ByteCNN-TCN
deep     = standard + CodeT5+/可选 Qwen 长上下文候选 + 项目级 GATv2
```
